# 课程笔记精选配图

默认启用；`SUMMARY_FIGURES=false` 可以关闭。服务器和本地 MLX 入口共用
`src/pipeline/summary_figures.py`，不改变音频识别、作业复核和公式正文。

每堂复用已下载的课件原图和作业截图，最多保留 12 个候选。没有足够课件时，
额外抽取最多 8 个视频帧；优先转录中提及图示的时刻，否则按时长均匀取样。
空白和过小图片先在本机过滤。OCR 的近似去重不会提前丢掉配图候选中新增的板书。
这些是有限抽样，不保证录播中每幅图都被捕获。

DeepSeek 原生多模态一次读取候选原图、对应时间、附近转录和已有笔记，选取
0–6 张清晰的示意图、曲线、表格或完整例题。返回的图 ID 和章节 ID 必须来自
输入白名单，图注必须是简短纯文本。可见元素另存为审核证据，不能据图猜作业
题号或补写正文结论。没有合适的图就保持文字笔记。

请求发送前在数据库记下 `reserved`；SDK 自动重试为 0。完整结果可复用，
失败、未完成、输入变化的请求均不会自动重发。识图不可用或失败时保留文字
笔记，记录状态和安全错误类型，审核时可见，不把它报成配图成功。

Markdown 仅含 `#icourse-figure-<JPEG SHA256>` 引用，不包含原校园地址或图片
Base64。精选 JPEG、时间、来源、图注和审核证据保存在该课次的
`meta('summary_figures:<sub_id>')`。历史覆盖、单堂增量、冲突保护和加密回读
均包含这个字段；数据库校验核对实际图像哈希和正文引用。

首版把图片负载放在**所属课程的加密分片**，全局元数据分片不携带图片。
每图最多 768 KiB，最多 6 张，因此课程分片会增大；浏览器会随课程分片下载
图片数据，再按需显示。浏览器的 `loading=lazy` 只延迟显示，不是独立网络
资源的懒下载。以后可迁移成单独加密附件，现阶段沿用已验证的整库往返格式。

GitHub Pages 解密后生成本地 Blob 图片地址，点击可在页内查看大图。切换课次后释放
旧图片地址；隐藏的 PPT 文本渲染不会误释放当前笔记图片。旧笔记仍按原样显示。
本地新课 `review` 导出 summary.md 和精选 figures/*.jpg，可复制阅读。
邮件/PDF 的现有安全渲染仍保留文字与图注，本版不附加课堂图片到邮件。

真实试跑验收应检查完整识别覆盖、视觉请求账本、实际原图清晰度、图注证据、
图片与章节对应关系、公式正文和课程日期；合成图片测试不能替代课堂验收。
