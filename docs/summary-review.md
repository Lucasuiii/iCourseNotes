# 摘要正确性审查

本地入口和 main 共用 LectureRunner。生成摘要、加入精选原图之后，额外进行一次 DeepSeek 审查，默认对已配置 DeepSeek 的运行生效。Qwen 的切块、精度及串行调度不变。旧笔记不会因此重新识别。

审查使用生成时的完整材料（转录、可用 PPT OCR、作业读图证据、局部复核和识别缺口提示），最终摘要、课程日期及实际选入的 JPEG。不会重新下载音频或再识别，也不会把没有的 PPT 当作已有证据。使用既有原生多模态 DeepSeek 路由，启用思考；这通常增加一次文本及精选图片输入的请求，实际费用和耗时取决于材料与响应长度。

六项检查：数学定义/公式/证明方向、课堂证据、题号页码、内容覆盖、课程上下文、配图和图注位置。返回逐字对应摘要的问题片段、具体理由、材料证据和修正建议。数学逻辑允许直接检验；教材常识不能冒充老师说过的内容。已明确保留的合理不确定项不强行判错。保留模型可能误判或漏判的边界；模型通过不能替代 ASR 覆盖和最终内容审核。

- `passed`：结构完整、六项检查齐全且无问题，才保存为完成摘要。
- `needs_revision`：错误或需人工处理的疑点；保留草稿，不写入完成摘要、不进入正常发布/邮件流程。首版只报告建议，不自动改写或循环审查。
- `failed` / `reserved`：失败或调用结果不明确，保留检查点，不自动重试、不重新生成摘要。
- `unavailable`：未配置 DeepSeek，维持其他供应商的既有流程，明确记录未审查，不能当作审查通过。

审查与草稿存在 `summary_review:<sub_id>`，绑定课程、课次、日期、材料及最终摘要哈希，随所属课程加密分片保存，不能跨课程合并。改动材料或摘要后需要明确处理旧审查状态，不自动重放 API。输入超过 240,000 字符（材料加摘要）会阻塞，不能截取部分材料后声称审查完整。审查请求上限 16,000 输出 token、360 秒超时，关闭 SDK 自动重试；响应截断、非 JSON 或伪造引文均拒绝。

本地新课预览额外导出 `summary-review.md`。若这一步阻塞，本课控制子目录保留 `summary-draft.md`、`summary-review.md`、候选数据库和原检查点。它们供人工核对，不是发布成果。现有人工审核/发布授权边界不变。

离线测试检验调用次数、失败保留、哈希及引文校验、完成门禁、真实图片传参、课程分片加密和合并。模拟模型响应只能证明这些流程约束，不能证明模型实际发现错误的准确率。
