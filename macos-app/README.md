# iCourseNotes macOS 应用

本机识别与笔记阅读的图形入口。它调用已经配置好的本地识别后端（`local-history.command` 同一套源码、Python 环境、加密 Store 与包装器模板），不替代也不修改它们。

## 三个页面

**识别**
- “检查新回放”：登录校园、读取最新 data 与课表，只读核对订阅课程是否有播放地址（不下载音频、不调用模型）。已有笔记、已删除、课表排除、本机已有任务的课次自动跳过，避免重复识别。
- 勾选课次后“开始识别”：按最新优先排队，单个 bf16 模型双块解码，保留 AAC、课件 OCR、作业视觉、精选配图、摘要与理论复核；完成后停在待审核，不自动推送或发邮件。同一时间只允许一个识别进程。
- 只在识别运行时显示 GPU、功耗、内存、温度和趋势（macmon，全机数据），以及阶段、识别块数和剩余时间估计；窗口顶部也会出现一个小状态条。
- “暂停”：本机阶段（获取音频、切分、识别）保存检查点后停止；云端阶段会提示，可选“本堂完成后暂停”。“继续”从断点续跑，已完成的块和课次不会重跑；失败课次需显式“重试失败课次”。

**笔记**
- 默认显示本学期，按课程折叠；左上角菜单切换到其他学期，搜索会跨所有学期。学期取自 data 的课程目录（如 `2026-20271` 显示为“2026–2027 秋季学期”），没有目录记录时按上课日期推断。
- 单页阅读：作业与课程事项是正文开头的提示框；KaTeX 公式离线渲染；配图点击放大，再点看原始尺寸；页末可展开整理转录和本机识别原文；字号可调。左侧列表可以整条收起。
- 本机新结果读完后点“审核通过”（四项确认），审核绑定所读内容的指纹，只记录在本机。
- 导出 PDF：工具栏“导出”可导出当前笔记（可附整理转录）；“批量导出…”按一个学期、一门课程或全部导出，每堂一个文件，或合并为一个按“学期 → 课程 → 课次”生成书签的 PDF。A4、浅色排版，分页避开段落、公式和配图中间。

**同步**
- “拉取最新”：从 GitHub data 解密最新笔记，加密缓存在本机（只读，不改云端）。
- “推送”：已审核课次逐堂推送，复用 `finalize.py` 的既有保护：备份最新 data、只替换这一堂并核对范围、加密往返、普通推送（不强推）、远端回读。成功后清理音频、明文数据库、临时 checkout、私密日志与冗余加密数据库备份；保留摘要、两份转录、精选图、运行状态与识别检查点。失败不自动重试。
- 邮件在推送对话框单独开启，默认关闭，只尝试一次。“检查”按推送流程在本机构建并校验候选库，不推送、不发邮件。
- 云端与本机冲突：推送前会读取最新 data。如果这堂课云端已有笔记（例如云端每日任务也识别了），对话框并排显示两份的字数、配图、模型和邮件状态，由你选择：
  - **保留云端**：本机结果标记为“已由云端版本取代”，不写入 data，本机文件保留。
  - **用本机覆盖云端**：需勾选确认；覆盖绑定你对比时看到的那份云端内容，若之后云端又变了会拒绝。被替换的云端笔记随推送前的整库加密备份保留（清理时不删），并另存 `replaced-cloud-summary.md`；邮件回执保留，不会因覆盖重发。已删除并永久忽略的课次不能覆盖。
  - 推送失败且没有写入 GitHub 时，可以重新选择后再推送；之前的尝试记录归档在 `app-attempt-N/`。

## 运行前提

应用需要一个已经按 [本机识别说明](../docs/local-history-refresh.md) 跑通的本机运行目录（下称项目根目录），其中包含：

```
work/local-runtime/active-source.json   当前使用的源码 worktree
work/local-runtime/templates/            受保护的单堂包装器模板（finalize.py 等）
work/qwen-local-asr-test-env/bin/python  共用 Python 环境
```

`.app` 放在项目根目录时自动识别，否则首次打开会让你选择。界面与桥接输出不包含密钥、登录信息、签名媒体地址或私密日志，后端异常只显示类型名。应用只启动和暂停它自己生成的队列；旧流程启动的队列只读显示。

## 构建

需要 Xcode 命令行工具（Swift 5.10+）和 macOS 14+。在源码目录（含 `Package.swift`）的父目录作为项目根目录时：

```bash
./build.sh
```

`build.sh` 把 `iCourseNotes.app` 生成到上一级目录，并把 `bridge/` 与 `web/` 打包进应用。应用使用本机临时签名，每次重新构建后 macOS 会再次询问是否允许访问“文稿”文件夹。

## 目录

```
Sources/ICourseNotes/   SwiftUI 应用
bridge/app_bridge.py    应用与后端之间的 JSON 命令桥（status / scan / start / pause / resume /
                        notes-sync / notes-list / note / approve / unapprove / push / compare /
                        keep-remote / remote）
bridge/templates/       应用启动时渲染到各课次目录的队列、单堂与推送脚本
bridge/tests/           test_queue_flow.py：模拟后端的队列 → 暂停 → 续跑（需要本机运行目录）；
                        test_overwrite.py：云端冲突时保留 / 覆盖规则（独立运行）
web/                    阅读页；KaTeX 0.16.21、marked 15.0.12、DOMPurify 3.4.16 离线副本，
                        与线上前端 SRI 一致；render.js 取自生产前端
tools/make_icon.swift   生成应用图标
```

测试：

```bash
<项目根目录>/work/qwen-local-asr-test-env/bin/python bridge/tests/test_queue_flow.py
```
