## 当前状态

- 这是 GitHub 独立仓库，未通过 Fork 接口创建。
- 首次推送前已将 Actions 关闭；工作流配置保留，但不会因迁移而自动获取课堂、运行定时任务、覆盖数据或发邮件。配置中的每日时刻仍为 17:07。
- 迁移的是代码和原有加密数据。`data` 保持原提交 `763bb70e016e229feff35350a212ba6b15988afd`，没有解密、重加密或重算旧课堂。
- PR、Issues、Actions 日志、artifacts 和 Pages 继续留在旧仓库，不会随 Git 推送迁移。旧库不删除，仍可查看历史证据与正式恢复产物。
- GitHub Secrets 的值不能通过 API 读回，迁移没有复制这些值。新库尚未配置 Secrets，也未创建新的数据库密钥；已有数据必须使用原 `DB_ENCRYPTION_KEY`。

GitHub 曾因旧 fork 的 Actions 使用情况暂停工作流。独立仓库迁移用于独立维护代码，不能用来绕过平台暂停或恢复同样的负载。每日完整课堂处理的执行位置需要另行确定；本机或独立服务自身调度是可评估的方向，Actions 中保留代码检查、构建与发布用途。

## 本地开发

迁移工作树的 `origin` 指向新独立仓库，`legacy` 指向原 fork，`upstream` 指向原作者。旧指定工作树及另一工作区的远端和未提交修改不受本次迁移影响。

代码基准在迁移前已有 664 项本地合成测试通过。迁移只更改名称、来源/部署说明和前端仓库输入占位文案，不修改处理实现或工作流；这不构成新仓库真实运行验证。

## 后续运行边界

概率论前两堂真实预览的授权保留，但本次迁移不会自动启动它。开始前须核验准确课次 ID、确定执行位置和配置私密凭据；保留旧结果、不发邮件，正式覆盖仍需另外确认新旧对照。

旧 owner、动态队列和冻结代码分支含旧仓库身份及 run ID，不复制到新运行环境。它们保留在旧库，必须在原身份下恢复，不能因新库不存在 owner 就重放旧的未知任务。原测试音频已清理，不假设仍可用。
